# Temperature Cowl Maker（気温で編むスヌード・パターンジェネレーター）仕様書

365日の実測気温データを読み込み、日々の気温に応じた配色でスヌード（ネックウォーマー）を編むための編み図パターンとビジュアルシミュレーションを生成するWebアプリケーションです。

海外の編み物コミュニティ（Ravelry等）で人気の高い「Temperature Cowl」「Temperature Blanket」カルチャーを、日本の気象データに合わせて手軽に楽しむことができます。

---

## 1. システム概要と特徴

* **ビルド不要のシンプル設計**: HTML5、JavaScript（Vanilla JS）、CSS3のみで構成。WebサーバーやNode.jsビルド環境を必要とせず、`index.html` をブラウザで直接開くだけで即座に動作します。
* **全国47都道府県対応**: 北海道から沖縄までの県庁所在地座標をプリセット。過去の気象データをワンクリックで自動取得。
* **ワンアクション設計**: 条件を選んで「パターンを生成する」を押すだけで、気象データの取得からカラー判定、編み図パターンの生成まで全自動で完了。
* **英文パターン（Garter Stitch）出力**: 海外の標準的な英文編み図様式（略語表記：CO, BO, k, sts）に準拠し、同色が続く日数を自動で集約したガーター編み指示書を出力。
* **プロジェクトの保存・復元**: 配色チャート・目数・気温データ・プロジェクト名をひとつのJSONファイルとしてエクスポート／インポート可能。

## 3. 機能詳細仕様

### 3.1 気象データ自動取得機能
* **観測地点**: 全47都道府県の県庁所在地（緯度・経度プリセット）。
* **対象年度**: 過去の観測年（例: `2024`）を指定。
* **気温種別**:
  * `temperature_2m_max`: 日最高気温
  * `temperature_2m_min`: 日最低気温
  * `temperature_2m_mean`: 日平均気温
* **自動命名連動**: 取得成功時、プロジェクト名が自動的に `[都道府県名] [年]年 ([気温種別])`（例: `長崎県 (長崎) 2024 (最高気温)`）に設定されます。
* **手動入力・編集対応**: 取得したデータは下部のテキストエリア（`temp-data`）に展開され、手動での修正や独自データの貼り付けも可能です。

### 3.2 カラーチャート（配色）仕様
日本の四季と気候変動を表現する環境配慮型カラー8段階をデフォルト定義しています。

| No. | 温度範囲 | デフォルト色名 / カラーコード | 気候イメージ |
| :---: | :--- | :--- | :--- |
| 1 | 35.0℃ 以上 | Deep Red (`#d63031`) | 猛暑日（朱色） |
| 2 | 30.0℃ 〜 34.9℃ | Orange (`#e67e22`) | 真夏日 |
| 3 | 25.0℃ 〜 29.9℃ | Mustard (`#f1c40f`) | 夏日（イエロー） |
| 4 | 20.0℃ 〜 24.9℃ | Apple Green (`#badc58`) | 過ごしやすい陽気（黄緑） |
| 5 | 15.0℃ 〜 19.9℃ | Green (`#1abc9c`) | 肌寒い春秋（ターコイズ） |
| 6 | 10.0℃ 〜 14.9℃ | Light Blue (`#81ecec`) | 寒さを感じる（水色） |
| 7 | 5.0℃ 〜 9.9℃ | Royal Blue (`#4a90e2`) | 冬の寒さ（青） |
| 8 | 5.0℃ 未満 | Purple (`#6c5ce7`) | 真冬の冷え込み（ナイトブルー） |

* **カスタマイズ機能**:
  * カラーピッカーによる16進数カラーコードの変更
  * 温度上限値（℃以下）の変更
  * ラベル名の編集（英文パターンに反映）
  * レンジの追加（`+ 追加`）および削除（`delete`）
  * デフォルト状態へのリセット（`初期化`）
  * 編集結果はブラウザの `localStorage` に自動保持

### 3.3 編み図生成・出力仕様

#### ① ビジュアルプレビュー
* 365日分の気温に合わせた色のストライプが縦方向に積層。
* 各段にマウスカーソルを乗せると「○日目：○℃（カラー名）」のツールチップが表示。

#### ② 必要玉数の目安（Required Yarn）
* 色ごとに365日のうち合計何段（何日分）編むかを集計して表示。毛糸の購入目安として活用可能。

#### ③ 英文パターン（Garter Stitch Instructions）
* ガーター編み（往復編みで毎段表編み）を基準とした指示書を自動生成。
* 同一色が連続する期間を自動集約（例: `Rows 1-15: With Purple (Night Blue), k all sts. (15 rows)`）。
* 作り目数（Cast on sts）の反映、略語解説（CO, k, BO, sts）を含む。
* テキストファイル（`.txt`）としてワンクリックダウンロード可能。

#### ④ 日別詳細リスト（Daily List）
* 通算日数（Day: 1〜365）、カレンダー日付（Date: YYYY-MM-DD）、気温（℃）、カラーコードおよび名称をテーブル表示。
* スヌードのプレビューバーにホバーした際にも、ツールチップに日付が表示されます。
* CSVダウンロード機能（`.csv`）: `Day,Date,Temperature,Color` のヘッダー付きで、Excelで直接開いても文字化けしないUTF-8 BOM付きCSVファイルとして保存可能。

### 3.4 プロジェクト管理（保存・ロード）
* **プロジェクト保存（`保存` ボタン）**:
  * プロジェクト名、カラーチャート設定、作り目数、気温データ、地域・年選択状態を包括した `.json` ファイルを出力。
* **プロジェクト読込（`ロード` ボタン）**:
  * 保存した `.json` を選択すると、設定および気温データが画面に復元され、即座に編み図が再描画されます。

## 4. 操作手順・ワークフロー

```text
[Step 1] 都道府県・年度・気温種別を選択
    ↓
[Step 2] 作り目（横幅）を確認（※任意でカラーパレットを微調整）
    ↓
[Action] 「パターンを生成する」をクリック
    ↓
[Result] 画面右側にビジュアルプレビュー・英文パターン・必要段数が即座に完成！
    ↓
[Save]   必要に応じて英文パターン(.txt)やプロジェクト設定(.json)をダウンロード
```
